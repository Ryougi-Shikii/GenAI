Langchain:
    agents       → autonomous/tool-using workflows
    chat_models  → LLM/chat-model abstraction
    tools        → functions the model can call
    messages     → representation of conversation
    prompts      → construction of model input
    embeddings   → text → vectors
    vectorstores → store/search vectors
    loaders      → load external data
    splitters    → divide documents into chunks
    runnables    → composable execution abstraction
    parsers      → model output → structured Python data
